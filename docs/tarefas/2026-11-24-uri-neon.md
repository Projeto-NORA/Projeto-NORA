# Conexão pela URL do Neon

## Pedido

Permitir que a URL PostgreSQL copiada do Neon seja colada diretamente na variável de ambiente do Render.

Skills e comandos invocados pelo usuário: nenhum nesta solicitação.

## Objetivo e restrições

Aceitar a URL e preservar as conexões Npgsql existentes, sem expor credenciais. Aplicar também às conexões das unidades.

## Checklist

- [x] Implementar leitura da URL e opções de conexão, preservando segurança.
- [x] Testar URL, credenciais codificadas, opções, erros e conexões antigas.
- [x] Atualizar a documentação e registrar os resultados.

## Estado

A API usa Npgsql, que espera parâmetros nomeados. O parser compartilhado aceita URLs PostgreSQL e atende a conexão central e a das unidades, preservando o formato anterior. Para o Neon com `sslmode=require`, exige a verificação do certificado. A documentação de hospedagem foi atualizada.

O build Release da solução passou sem erros nem avisos. A suíte da API com PostgreSQL descartável terminou com código 0, incluindo conexão por URL, credenciais codificadas e verificação do certificado. A versão modificada ainda precisa ser publicada no Render antes de usar a URL lá; a conexão ao Neon real não foi testada nesta tarefa.
