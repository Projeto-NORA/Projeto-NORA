# Galeria da revisão visual do APPNORA

Abra [index.html](index.html) para conferir as 59 imagens dos temas claro e escuro. As prévias foram renderizadas a partir dos componentes Compose, com dados fictícios; algumas mostram telas completas e outras, estados ou partes de tela.

O mapa não é suportado pelo renderizador usado: na prévia da tela UBS ele foi substituído por um aviso em uma cópia isolada. As imagens não são capturas de aparelho e não comprovam a entrega de notificações. A pulsação da abertura só aparece em movimento no aplicativo.
