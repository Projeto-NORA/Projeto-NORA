# Marca NORA nos dois temas

A [galeria](index.html) mostra seis prévias Compose de abertura, login e início nos temas claro e escuro. A marca transparente foi gerada a partir das duas imagens fornecidas com a ferramenta ImageGen; os originais foram preservados. O app aplica uma matriz de cores em tempo de desenho no modo escuro, clareando o azul e preservando a distinção das áreas verdes e amarelas.

Pedidos usados para a geração: remover somente o fundo externo e preservar a marca, incluindo cruz, estrelas, ondas, engrenagem, faixas, cores e proporções; na marca completa, manter também o texto “CUIDAR É CONECTAR. TECNOLOGIA É TRANSFORMAR VIDAS.”. Solicitar transparência real, sem borda, sombra ou elementos extras.
